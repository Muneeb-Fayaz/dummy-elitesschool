# The Elite's Co-Ed School, Srinagar — Demo Website

🔗 **Live Demo:** https://muneeb-fayaz.github.io/dummy-elitesschool/

---

A responsive, single-page demo website for **The Elite's Co-Ed School**, a CBSE co-educational school in Srinagar, Jammu & Kashmir. This is a **dummy/prototype project**: names, photos, ranks and social links are placeholders to be replaced with real content.

## Features

- **Hero slider** with rotating welcome slides and call-to-action buttons
- **Stats counter**: students enrolled, qualified teachers, pass rate, years of excellence
- **Principal's message** section
- **About the school**: CBSE curriculum, arts & culture, sports & fitness, science labs
- **Faculty** cards with subject, qualification and experience
- **Toppers** section with Class 8 and Class 10 tabs (ranks 1–5)
- **Parent reviews** (testimonials)
- **Photo gallery** with category filters (Campus, Events, Sports, Academics) and a full-screen lightbox with Prev/Next navigation
- **Contact & location**: address, school hours, phone/WhatsApp link, social links and an embedded Google Map
- **SEO-ready**: meta description, keywords, Open Graph and Twitter Card tags, geo tags
- **Mobile-friendly** layout with anchor-based navigation

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/muneeb-fayaz/dummy-elitesschool.git
   cd dummy-elitesschool
   ```
2. Open `index.html` in your browser, or serve it locally:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.
